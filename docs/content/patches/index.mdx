---
title: Patches
description: Every change Offload makes to Payload, why, and the upstream change that makes each one unnecessary.
---

Offload is Payload at the commit pinned in [`upstream/payload.json`](https://github.com/AdiRishi/offload-cms/blob/main/upstream/payload.json), plus the patches below. Each page says what breaks without the patch, links the upstream pull request when there is one, and names the condition for dropping the patch.

A patch is for behaviour that Payload's config or plugin API can't express. [Make a change](/contributing/making-changes) explains when to write one.

:::note
`pnpm upstream export` generates these pages from the patches' commit messages. To change a page, change the commit.
:::
