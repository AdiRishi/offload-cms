---
title: Patches
description: What Offload changes in Payload, why, and the condition under which each change can be dropped.
---

Offload is upstream Payload at the commit pinned in [`upstream/payload.json`](https://github.com/AdiRishi/offload-cms/blob/main/upstream/payload.json), plus one patch per change below. Each patch is a commit whose message explains what breaks without it, links the upstream pull request when there is one, and names the condition under which upstream makes it unnecessary.

A patch is for behaviour that Payload's config or plugin API can't express. [Changing Payload](/contributing/changing-payload) covers when to write one and how.

:::note
`pnpm upstream:export` generates these pages from the patches' commit messages. Edit the commit, not the page.
:::
