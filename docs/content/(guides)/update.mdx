title: Update Offload
description: Move a site to a new Offload release, and check that a package came from this repository's release workflow.

## Move to a new release

Every Offload package in a site must have the same version. Change each `@adirishi/offload-*` version in `package.json` to the new release, including the npm aliases, then install.

From a checkout of this repository, one command does the edit:

```bash
pnpm release use-version ../my-site {{version}}
```

Leave out the version to use the latest release.

The registry serves components for the latest release only. If the site installed Offload's form, account, or checkout components, add them again with `--overwrite` after the update, and review the diff.

## Verify a package

Published tarballs from `4.0.0-beta.2-offload.11` on have a signed build provenance attestation, which ties the tarball to the commit and the workflow run that built it. To check a package, download it and verify it with the GitHub CLI:

```bash
npm pack @adirishi/offload-payload@{{version}}
gh attestation verify adirishi-offload-payload-{{version}}.tgz --repo AdiRishi/offload-cms
```
