You need Node 24 and pnpm through Corepack. Docker is needed only for the Postgres test run.

```bash
pnpm install
pnpm upstream checkout
pnpm check
```

`pnpm upstream checkout` clones Payload at the pinned commit into `upstream/payload` and applies the patches. `pnpm check` runs the linter, the format check, the type checks, and the tests.

## Layout

<FileTree>

- packages/
  - cloudflare/ `@adirishi/offload-cloudflare`, published
  - tsconfig/ `@repo/tsconfig`, the TypeScript configs that every package extends
- upstream/ `@repo/upstream`
  - payload.json the pinned Payload release
  - patches/ one `git format-patch` file per change to Payload
  - payload/ the Payload checkout, created by `pnpm upstream checkout`
  - src/ the `upstream` CLI
- release/ `@repo/release`, the `release` CLI
- e2e/ a Payload site on Workers that the Playwright suite drives
- docs/ this site

</FileTree>

The pnpm workspace holds `docs`, `packages/*`, `upstream`, and `release`. Every dependency version comes from the catalog in `pnpm-workspace.yaml`. Node runs the `upstream` and `release` CLIs straight from TypeScript. `e2e` is a separate pnpm project, because it installs Offload from a registry the way a site does.

## Commands

| Command                                         | What it does                                                                      |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| `pnpm check`                                    | Lint, format check, type checks, and tests                                        |
| `pnpm format:fix`, `pnpm lint:fix`              | Fix formatting and lint problems                                                  |
| `pnpm build`                                    | Build Payload, the packages in `packages/`, and this site                         |
| `pnpm docs:dev`                                 | Serve this site locally                                                           |
| `pnpm upstream checkout [--force]`              | Create `upstream/payload` from the pin and the patches                            |
| `pnpm upstream export`                          | Write the commits in `upstream/payload` to `upstream/patches` and the patch pages |
| `pnpm upstream status [--against <tag>]`        | Show each patch's upstream pull request, and whether `<tag>` already contains it  |
| `pnpm upstream upgrade <tag> [--drop <id>]`     | Move the patch series to a newer Payload release                                  |
| `pnpm release e2e [--postgres]`                 | Publish the working tree to a throwaway registry and run the e2e suite            |
| `pnpm release use-version <site-dir> [version]` | Point a site's Offload dependencies at a release                                  |
| `pnpm release publish`                          | Build and publish the packages at the pinned version to `OFFLOAD_REGISTRY`        |

Run `pnpm upstream` or `pnpm release` with no command to print its options.

## Editor

Install the recommended oxc extension. `.vscode/settings.json` formats on save, applies lint fixes, and turns on type-aware lint rules.
