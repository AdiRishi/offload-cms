## 1. fix(payload): cap PBKDF2 iterations on Cloudflare Workers

Cloudflare Workers rejects PBKDF2 above 100,000 iterations, and Payload hashes
passwords with 600,000. On a deployed Worker, creating the first user and every
login fail with "iteration counts above 100000 are not supported". Local
workerd does not enforce the limit, so only a deployed Worker shows it.

The patch caps iterations at 100,000 when navigator.userAgent is
Cloudflare-Workers and stores the iteration count in the hash
(pbkdf2-sha256-v2-i<iterations>-l<keyLength>:<hex>), so any runtime can verify
it. Hashes made at 600,000 iterations elsewhere still cannot be verified on
Workers, so seed users through the Worker, not the Node CLI.

Tests: pnpm --filter payload exec vitest run src/auth/strategies/local; Workers smoke suite against a deployed Worker

## 2. fix(plugin-search): drop the unused @payloadcms/next dependency

plugin-search lists @payloadcms/next as a runtime dependency but never imports
it. Installing the plugin in a TanStack Start site therefore installs all of
Next.js 16 and a next peer requirement. Removing the dependency changes nothing
at runtime.

Tests: pnpm --filter @payloadcms/plugin-search build; e2e suite (search test) passes and apps/e2e has no next package installed
